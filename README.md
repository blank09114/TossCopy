# 금융 애플리케이션

---
## 프로젝트 개요

Java Swing을 활용해 구현한 데스크톱 급융 애플리케이션입니다. 회원가입/로그인 후 계좌를 생성하고, 송금/인출, 주식 거래, 이벤트 등 다양한 금융 기능을 사용할 수 있도록 구성했습니다.
- 개발 형태: 데스크톱 애플리케이션
- 개발 인원: 4인

---
## 기술 스택

| 구분 | 기술 |
|------|------|
| Language | Java |
| UI | Java Swing |
| Dev Tools | Eclipse |

---
## 구조 및 설계
### 전체 구조

객체 지향 구조를 기반으로 사용자, 계좌, 거래 내역을 각각 독립된 객체로 관리했습니다. 데이터는 파일 입출력을 통해 저장 및 불러오는 방식으로 구성했습니다.

### 클래스 설계

Account 추상 클래스를 기반으로 입출금 계좌와 주식 계좌를 분리해 설계했습니다. 거래 내역은 History 객체로 관리하고, 이벤트 및 포인트 관련 로직은 별도의 EventManage 클래스로 분리했습니다. 이러한 구조를 통해 기능별 책임을 분리하고, 계좌 유형에 따라 다른 동작을 수행할 수 있도록 구성했습니다.

---

## 주요 기능

- 회원: 회원가입 및 로그인 기능
- 계좌: 계좌 생성, 연결, 수정, 삭제
- 거래: 송금 및 인출, 거래 내역 조회
- 주식: 주식 조회, 매수/매도, 가격 변동
- 이벤트: 퀴즈 기반 포인트 적립 및 환전

---
## 구현
### 이벤트 시스템(퀴즈)

퀴즈 데이터를 배열 형태로 관리하고, 무작위로 문제를 출제하는 구조로 구현했습니다. Random 클래스를 활용해 문제를 선택하고, 사용자 입력을 받아 정답 여부를 판별했습니다. 난이도 및 정답 여부에 따라 포인트를 차등 지급하며, 중복 참여를 방지하기 위해 상태 플래그를 사용했습니다.

### 포인트 환전 기능

보유 포인트를 계좌 잔액으로 전환하는 기능을 구현했습니다. 환전 시 입력값 검증(1000 단위, 보유 포인트 이하)을 수행하고, 조건을 만족할 경우 계좌 잔액을 증가시키는 방식으로 처리했습니다.

### 계좌 및 거래 관리

계좌 생성, 수정, 삭제 및 연결 기능을 구현하고, 사용자별 계좌를 필터링해 관리했습니다. 송금 및 인출 시 잔액 검증을 수행하고, 거래 내역은 History 객체로 기록 후 파일에 저장하도록 구성했습니다.

### 주식

주식 가격을 일정 시간마다 랜덤으로 변동시키고, 이를 UI에 반영하도록 구현했습니다. 사용자는 주식을 매수/매도할 수 있으며, 보유 수량과 평균 매수가를 기준으로 상태를 관리했습니다.

### GUI 구조

Java Swing을 활용해 화면을 구성하고, 기능별로 Frame을 분리했습니다. 계좌 관리, 거래, 주식, 이벤트 기능을 각각 독립된 화면으로 구성하고, 사용자 선택에 따라 화면이 전환되도록 구현했습니다.

## 기술적 고민 및 개선점
### 데이터 관리 방식

파일 입출력을 사용해 데이터를 관리했지만, 동시성이나 데이터 무결성 측면에서 한계가 있었습니다. 향후에는 데이터베이스를 도입해 안정성과 확장성을 개선할 필요가 있습니다.

### 보안 처리

비밀번호 암호화 및 입력값 검증이 충분하지 않았습니다. 실제 서비스 수준에서는 암호화 처리와 보안 로직을 추가해야 한다고 판단했습니다.

### 구조 확장성

기능이 증가하면서 일부 로직이 특정 클래스에 집중되는 문제가 발생했습니다. 역할 분리를 더 명확히 하고 구조를 개선할 필요가 있습니다.

### 실시간성

주식 가격 및 금융 데이터는 내부 로직으로만 처리되어 실제 서비스와 차이가 있습니다. 외부 API 연동을 통해 보다 현실적인 시스템으로 확장할 수 있습니다.
