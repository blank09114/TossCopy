# 💸 Java GUI Banking System

> **Java GUI 기반 금융 시스템 구현 프로젝트**  
> 계좌 입출금, 송금, 이벤트(출석/퀴즈/포인트 등) 기능을 포함한 데스크탑 금융 애플리케이션입니다.

---

## 💡 프로젝트 개요

> Java의 GUI 라이브러리를 활용해 구현한 금융 애플리케이션입니다. 계좌 시스템과 이벤트 기능(출석체크, 퀴즈, 포인트 환전 등)을 포함하며, 사용자 중심의 버튼 인터페이스와 팝업 기반의 정보 입력 흐름을 구현했습니다.

---

## 🖥️ 기술 스택

- **Language**: Java (JDK 11)
- **GUI Framework**: Java Swing (JFrame, JPanel 등)
- **IDE**: Eclipse

## 💼 담당 파트

### 🎉 이벤트 시스템
- 출석체크 기능 구현(중복 방지, 횟수 누적 등)
- 퀴즈 기능 설계 및 정답 처리, 포인트 지급
- 포인트 누적/소비/환전 기능 구현
- GUI 기반 입력창 및 결과 안내 팝업 구성

### 🧩 클래스 구조 설계
- 이벤트 관련 클래스 설계 (`EventManager`, `Quiz`, `PointManager` 등)
- 클래스 다이어그램 문서화

### 📊 발표 및 문서 작업
- 발표 자료(PPT) 제작 및 팀 대표 발표 담당

## 🔍 주요 기능

| 기능 영역 | 설명 |
|----------|------|
| 계좌 관리 | 사용자 계좌 생성, 입금, 출금, 송금 (GUI 버튼 인터페이스) |
| 거래 내역 | 주요 작업 후 콘솔/팝업으로 거래 내역 표시 |
| 이벤트 시스템 | 출석 체크 / 퀴즈 풀이 / 포인트 지급 |
| 환전 기능 | 포인트를 계좌 잔액으로 전환 가능 |
| 사용자 인터페이스 | `JFrame` 기반 다중 창 구성, `JButton` 이벤트 처리 |
