# 💸 Java GUI Banking System

계좌 입출금, 송금, 이벤트(출석/퀴즈/포인트 등) 기능을 포함한 **Java GUI 기반 데스크톱 금융 애플리케이션**입니다.

---

## 📌 프로젝트 개요
- **개발 형태**: 데스크탑 GUI 애플리케이션
- **개발 인원**: 4인 (권지언, 박예린, 박시우, 황예지)  
- **핵심 목표**: 계좌 시스템과 이벤트 기능을 포함한 GUI 금융 서비스 구현  

---

## 🖥️ 기술 스택
| 분야 | 사용 기술 |
|------|-----------|
| Language | Java(JDK 11) |
| GUI Framework | Java Swing(`JFrame`, `JPanel`, `JButton` 등) |
| TOOL | Eclipse |

---

## 🔍 주요 기능
| 기능 영역 | 설명 |
|-----------|-------|
| 계좌 관리 | 계좌 생성, 입금, 출금, 송금(버튼 기반 인터페이스) |
| 거래 내역 | 작업 후 콘솔/팝업으로 거래 내역 표시 |
| 이벤트 시스템 | 출석 체크/퀴즈 풀이/포인트 지급 |
| 환전 기능 | 포인트 → 계좌 잔액 환전 가능 |
| 사용자 인터페이스 | `JFrame` 기반 다중 창, `JButton` 이벤트 처리 |

---

## 💼 담당 파트

### 🎉 이벤트 시스템
- 출석체크 기능 (중복 방지, 횟수 누적)  
- 퀴즈 기능 설계 및 정답 처리, 포인트 지급  
- 포인트 누적/소비/환전 기능 구현

### 🧩 클래스 구조 설계
- 이벤트 관련 클래스 (`EventManager`, `Quiz`, `PointManager` 등) 설계
- 클래스 다이어그램 문서화

### 📊 발표 및 문서 작업
- 발표 자료(PPT) 제작  
- 팀 대표 발표 담당

---

## ⚙️ 기술적 구현
- **클래스 기반 설계**: 이벤트 시스템을 모듈화해 `EventManager`, `Quiz`, `PointManager` 등으로 분리
- **상태 관리**: 출석 횟수, 포인트 잔액을 멤버 변수로 관리하고 조건문을 통해 중복 방지 로직 구현  
- **다중 창 구성**: 메인 계좌 관리 화면과 이벤트 화면을 분리하여 사용자 흐름 단순화

---

## 🎯 협업 경험
- 클래스 다이어그램 및 GUI 흐름도 공동 작성  
- 발표 자료 및 테스트 시나리오 팀 내 협업  
- 역할 분담 후 기능 통합(계좌 관리 / 이벤트 / UI)
